# RaceCoach

Lokalny system zarządzania stanowiskami Assetto Corsa i szkoleniem kierowców.

Serwer i panel instruktora, konta kursantów, indywidualne plany, sesje indywidualne i grupowe,
agent Windows, monitoring, archiwum telemetrii oraz porównania sekcji toru.

## Etapy

1. Architektura i repozytorium.
2. Serwer, tożsamości, kursanci, plany i protokół stanowisk.
3. Sesje, telemetria, sekcje i porównania.
4. Agent z adapterami Assetto Corsa oraz DD Control.
5. Panel instruktora i integracja.
6. Weryfikacja i instrukcja stanowiska Windows.

Szczegóły uruchomienia i status integracji będą uzupełniane razem z implementacją.
